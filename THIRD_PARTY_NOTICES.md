# Third-party notices

`src/components/AnimatedContent.tsx` adapts the React Bits AnimatedContent pattern by David Haz from [React Bits](https://github.com/DavidHDev/react-bits/blob/main/src/content/Animations/AnimatedContent/AnimatedContent.jsx). The local version is written in TypeScript, uses an `active` motion preference and retains readable content before animation.
